The simple version

An analyst who knows where everything is.

A good analyst hears a question in normal language, knows which table holds the answer, writes the query and explains the result.

For engineers

What decides whether it works

The semantic layer does the heavy liftingClear table names, descriptions and agreed measures matter more than which model you pick.
Data agents have limitsAn agent takes up to five sources and is read-only. Scope it to one subject area, not the whole company.
Security still appliesThe agent respects the permissions of the person asking. Row and column rules still decide what comes back.
Copilot needs paid capacityIt is on by default for paid Fabric capacities from F2 up, and not available on trial.
The honest part

Is your data ready for AI?

Ready when

  • Gold tables are clean and documented
  • KPIs have one agreed definition
  • Access rules are already in place

Not yet when

  • Column names are cryptic codes
  • Three tables claim to be "sales"
  • Nobody can say which number is right

The catch: an agent makes a bad data model fail faster and more confidently. It will answer every question, including the ones your data cannot support.
