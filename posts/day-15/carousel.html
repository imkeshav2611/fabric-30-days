The problem

Analysts want live data. Databases want to be left alone.

Every team ends up choosing between fresh data and a healthy database.

The simple version

A mirror, not a photograph.

A photograph shows how things looked when you took it. A mirror shows how they look now.

Mirroring keeps a continuously updated copy of your database in OneLake, ready for analytics.

✓You doPick the database and tables
✓Fabric doesThe copying, continuously
✓You getDelta tables, a few moments behind
How it works

What happens behind the mirror

1Fabric takes an initial snapshot of the tables
2It then reads the changes as they happen
3Changes land as Delta tables in OneLake
4A SQL analytics endpoint lets you query them
Three kindsDatabase mirroring copies data. Metadata mirroring links a catalog. Open mirroring lets any system push changes in.
For engineers

The fine print that matters

Many sources nowAzure SQL, SQL Server, Cosmos DB, PostgreSQL, Snowflake, Oracle, SAP, BigQuery and Databricks catalogs, among others.
What is freeReplication compute is free. Storage is free up to 1 TB per capacity unit. Querying uses capacity as normal.
It is a replica, not a transformationTables arrive as they are in the source. Cleaning and modelling still happen downstream.
Read-onlyYou query the mirror. You do not write to it.
The honest part

Mirror it or build a pipeline?

Mirror

  • You need the tables as they are, kept fresh
  • The source is on the supported list
  • You want less code to maintain

Pipeline

  • You only need a small filtered slice
  • The source is not supported
  • You must reshape data before it lands

The catch: mirroring gives you a raw copy of an operational schema. Without a Silver layer on top, analysts inherit every quirk of the application database.

Watch out

Four checks before you mirror

1Unsupported tables or column types in your source
2Network path: can Fabric reach the database?
3Retention of history on the mirrored tables
4Who models the data after it lands

Mirroring replaces the ingestion pipeline, not the modelling work.
